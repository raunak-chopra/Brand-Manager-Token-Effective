# Shared Reference Library

Use this for reusable references that are not tied to one brand.

Brand-specific references belong inside:

```text
brands/[Brand Name]/reference-library/
```

## Folder Map

| Folder | Use For |
|---|---|
| `fonts/` | General font examples, foundry links, pairings, typography inspiration |
| `colors/` | Palette examples, color systems, swatches, contrast references |
| `layout-systems/` | Grid systems, deck layouts, packaging systems, web layout examples |
| `moodboard-styles/` | General aesthetic directions and territory examples |
| `photography/` | General photo styles, lighting, crops, art direction examples |
| `packaging/` | Packaging inspiration across categories |
| `websites/` | Website examples and UI references |
| `social/` | Social templates, post styles, carousel references, reels examples |
| `competitors/` | Category-wide competitor examples not assigned to one brand yet |
| `claims-compliance/` | General claim, legal, health, and compliance references |
| `tools-and-prompts/` | Reusable prompts, AI tools, and workflow notes |
| `tools-and-prompts/envato-asset-library-guide.md` | External Envato catalog guide for templates, mockups, fonts, packaging assets, UI kits, and design inspiration |

## Rules

- Keep filenames descriptive.
- Add notes when the reason for saving a reference is not obvious.
- Do not mix approved brand references here.
- Move brand-specific items into that brand's folder once a project starts.
- If a reusable pattern becomes useful across brands, summarize the learning in the relevant `skills/[skill]/` file instead of relying on the raw reference alone.
- Do not treat inspiration as proof, license approval, legal guidance, or market data.
- When brand and shared reference folders are empty or insufficient, use the Envato asset catalog as a support library. Brand rules still override Envato references.
- Treat supplied asset/reference folders as usable only when license proof or usage approval has been supplied. Do not invent specific license terms or usage rights beyond supplied confirmation.
