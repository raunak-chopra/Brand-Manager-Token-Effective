## Priority Rule

1. Brand authority docs win: `brands/[Brand]/context-index.md`, brand guidelines, and confirmed brand rules.
2. Brand-owned assets and exports come next when they exist.
3. Brand or shared reference folders are useful only when the relevant folder has files.
4. Envato is the fallback/support library for visual references and source assets.
5. General model knowledge is last and should be labeled as general guidance.

Envato never overrides confirmed brand rules for colors, typography, logo use, voice, claims, legal constraints, or mandatory/rejected styles.

## When To Use Envato

- Finding presentation, proposal, report, and pitch deck references.
- Finding PSD mockups, product effects, packaging references, and visual treatments.
- Finding fonts or typography inspiration, using supplied licensed items where available.
- Finding UI kits, website layouts, Elementor kits, WordPress themes, and Shopify themes.
- Finding visual directions when brand/shared reference folders are empty.

## When Not To Use Envato

- To invent brand rules.
- To invent license terms, redistribution rights, or third-party usage permissions.
- To prove claims, market data, legal guidance, or competitor facts.
- To replace a brand's context index, brand guidelines, approved assets, or rejected-style rules.

## Usage Workflow

1. Read the relevant brand context first.
2. Check whether the relevant brand/shared reference folder has files.
3. If local references are empty or insufficient, search `Envato_Asset_Catalog.json`.
4. Pick relevant `asset_id` values and inspect only those asset rows/folders.
5. Copy selected assets into the active brand/project workspace before editing.
6. Before client delivery or external publication, confirm the selected asset is from the licensed supplied library or has its own current license record.
7. Keep `C:\Users\raunak.chopra\Downloads\Envato_Organized` read-only.
