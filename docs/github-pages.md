# GitHub Pages Setup

Use this after the `marketing-bot` repository exists on GitHub and the first commit has been pushed.

## Settings

- Repository: `raunak-chopra/marketing-bot`
- Visibility: private
- Pages source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`
- Expected URL: `https://raunak-chopra.github.io/marketing-bot/`

## Update Rules

1. Keep public-facing docs free of secrets, raw exports, private customer data, and unsupported claims.
2. Update `docs/index.md` when important workspace entry points change.
3. Update `README.md` and `tools/integrations/github.md` if the Pages URL or repository settings change.
