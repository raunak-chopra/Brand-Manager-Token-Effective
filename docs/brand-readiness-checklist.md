# Brand Readiness Checklist

Use this before substantial brand, campaign, creative, email, CRO, or visual identity work. Do not turn missing inputs into assumptions; use `[To be supplied]`.

## Required Inputs

| Input | Needed For | Status |
|---|---|---|
| Product and category | All brand and campaign work | `[To be supplied]` |
| Primary audience | Strategy, copy, media, email, social, CRO | `[To be supplied]` |
| Core promise | Positioning, copy, identity, ads | `[To be supplied]` |
| Desired perception | Brand, visual identity, voice, campaigns | `[To be supplied]` |
| Competitors or category references | Positioning, research, visual differentiation | `[To be supplied]` |
| First-use touchpoints | Identity, launch, lifecycle, CRO | `[To be supplied]` |
| Mandatory assets | Visuals, ads, landing pages, brand book | `[To be supplied]` |
| Mandatory colors/fonts | Identity, brand book, design execution | `[To be supplied]` |
| Approved claims and proof | Copy, ads, email, CRO, brand guidelines | `[To be supplied]` |
| Legal or compliance rules | Claims, regulated categories, external copy | `[To be supplied]` |
| Rejected styles | Visual identity, voice, creative review | `[To be supplied]` |
| Reference folders | Moodboards, visual identity, creative direction | `[To be supplied]` |

## Readiness Levels

| Level | Meaning | What To Do |
|---|---|---|
| Ready | Most required inputs are supplied and source paths are known. | Produce the requested deliverable and flag minor gaps. |
| Partially Ready | Core strategy exists, but proof, assets, references, or metrics are missing. | Produce a draft with `[To be supplied]` placeholders and risk notes. |
| Not Ready | Product, audience, promise, or desired perception is missing. | Ask only the missing questions needed to start. |

## Workflow Checks

| Workflow | Minimum Inputs |
|---|---|
| Brand strategy | Product, category, audience, promise, desired perception, proof, competitors. |
| Visual identity | Brand strategy, desired perception, touchpoints, approved/rejected references, assets, color/font rules. |
| Paid media | Offer, audience, geography, platform, budget, conversion event, tracking status, claim rules. |
| Email lifecycle | Audience, lifecycle stage, trigger, goal, offer/product moment, compliance rules. |
| Social content | Audience, platforms, goal, voice, source assets, cadence. |
| CRO | Page URL/copy/screenshot, conversion event, audience, traffic source, proof, current metrics. |

## Output Rule

For substantial deliverables, include a compact readiness note:

- Ready inputs used.
- Missing inputs marked `[To be supplied]`.
- Claim/source/legal risks.
- Asset or reference gaps.
