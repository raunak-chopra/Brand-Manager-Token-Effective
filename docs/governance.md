# Governance

## Runtime Ownership

- Repeated operating rules belong in `_core/`.
- Specialist behavior belongs in `agents/`.
- Reusable workflows belong in `skills/`.
- Deliverable layouts belong in `templates/`.
- Human explanations belong in `docs/`.
- Archived detail belongs in `_legacy/`.

## Duplication Rule

If a rule appears in three places, move it into `_core/` and point to it.

## Archive Rule

Do not delete useful old guidance. Move verbose or superseded files to `_legacy/` and keep active runtime compact.
