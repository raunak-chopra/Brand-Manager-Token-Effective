# Creative Output Structure

Use this structure for shareable or generated creative work:

```text
outputs/[Brand]/
  creative/
    concepts/
      [campaign-or-route]/
        prompts.md
        review-board.md
        images/
    final/
      [asset-name]/
    reports/
      creative-review.md
```

## Rules

- `concepts/` is exploratory and not final.
- `final/` is approved/export-ready.
- Every concept batch should include `prompts.md` and `review-board.md`.
- Do not overwrite prior generated concepts; version by date or route name.
- Store brand memory of prompts, approvals, winners, and rejected territories in `brands/[Brand]/`.
