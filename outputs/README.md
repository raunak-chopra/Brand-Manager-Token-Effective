# Brand Outputs

Use this folder for final or shareable deliverables.

```text
outputs/
  [Brand Name]/
    YYYY-MM-DD-[deliverable-name].md
```

Reusable layouts live in `templates/`.

Legacy output templates are preserved in `_legacy/2026-06-01-pre-superbot/output-templates/`.

## Rules

- Keep source-of-truth facts in `brands/[Brand Name]/`.
- Keep reusable layouts in `templates/`.
- Do not store raw platform exports, secrets, API responses, or unredacted customer/contact data here.
