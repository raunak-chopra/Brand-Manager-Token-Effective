# Campaign System

Use for launch plans, campaign ideas, content systems, social planning, editorial calendars, distribution, repurposing, and ad creative rollout sequencing.

## Inputs

Brand, offer, audience, channel mix, goal, budget/timeline, assets, proof, conversion event, current channels.

## Modes

| Mode | Use When | Optional Reference |
|---|---|---|
| Campaign Plan | launch or promotion structure | `templates/campaign/campaign-plan.md` |
| Content System | pillars, calendar, distribution | `_legacy/2026-06-01-pre-superbot/skills/content-system/references/content-strategy-playbook.md` |
| Social | platform-native posts or calendar | `_legacy/2026-06-01-pre-superbot/skills/social-content-system/references/platforms.md` |
| Repurposing | turn one asset into many | `_legacy/2026-06-01-pre-superbot/skills/content-system/references/repurposing.md` |
| Ad Creative Rollout | creative matrix, test plan, sequencing | `references/ad-creative-orchestration.md` |

## Workflow

1. Define goal, audience, offer, and conversion event.
2. Map channels to funnel stage and message job.
3. Create the minimum viable campaign system.
4. Assign assets, proof, cadence, and measurement.
5. Identify missing facts and dependencies.

## Output

Plan, channel roles, content/ad matrix, timeline, measurement, missing inputs.
