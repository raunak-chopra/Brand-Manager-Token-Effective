# Moodboard Workflow

Use moodboards to test strategic territories, not just aesthetics.

## Process

### 1. Create Territories

Develop 2-3 distinct visual routes. Each route must be different in strategic intent, not just color.

Recommended territory types:
- Category leader: builds trust by refining familiar category codes
- Challenger: breaks category conventions to stand out
- Cultural/editorial: creates lifestyle relevance and social energy
- Technical/systematic: uses structure, proof, data, and precision
- Sensory/emotional: uses texture, depth, warmth, and human cues

### 2. Build Each Moodboard

Each moodboard should include:
- 3-5 color references
- 2-3 typography references
- 3-5 imagery references
- 2-3 layout references
- 1-2 graphic device references
- 1-2 application references

### 3. Explain The Logic

For each territory:

```markdown
## Territory [Number]: [Name]

### Strategic Idea
[One clear sentence]

### Intended Perception
[What the audience should feel]

### Visual Keywords
[5-7 concrete words]

### Color Direction
[Palette behavior and emotional role]

### Typography Direction
[Typeface personality and hierarchy]

### Imagery Direction
[Photography, illustration, texture, or render style]

### Layout Direction
[Grid, spacing, density, composition]

### Graphic Devices
[Shapes, patterns, lines, icons, symbols, gradients]

### Best For
[Touchpoints where this route works strongest]

### Risks
[Why this may fail or need care]
```

### 5. Recommend One Direction

Recommend the direction that best balances strategy fit, distinctiveness, and execution practicality.

Do not recommend a route only because it looks the most visually exciting.
