# Visual Identity Evaluation Rubric

Use this before finalizing moodboards, brand books, or visual assets.

## Scoring

Score each criterion from 1-5.

| Score | Meaning |
|---:|---|
| 1 | Weak or off-brief |
| 2 | Partially useful but needs major revision |
| 3 | Acceptable but not distinctive |
| 4 | Strong and usable |
| 5 | Excellent and highly ownable |

## Criteria

| Criterion | Question |
|---|---|
| Strategy fit | Does it express the brand promise and positioning? |
| Audience relevance | Will the primary audience understand and trust it? |
| Category fit | Does it retain enough category cues to be legible? |
| Distinctiveness | Is it meaningfully different from competitors? |
| Scalability | Can it work across packaging, web, social, ads, and decks? |
| Usability | Can a designer or agency apply it without constant explanation? |
| Accessibility | Are contrast, readability, and hierarchy strong enough? |
| Consistency | Do colors, type, imagery, and layout feel like one system? |
| Production practicality | Can it be executed within realistic time, budget, and vendor limits? |
