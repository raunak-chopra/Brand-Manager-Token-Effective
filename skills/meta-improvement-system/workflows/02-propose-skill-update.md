# Propose Skill Update

Use this workflow when a candidate should become a skill, router, template, or policy update.

## Steps

1. Open only the target file.
2. Identify the smallest insertion or edit.
3. Preserve existing style and structure.
4. Apply the change only when requested.
5. Mark the candidate `Actioned` and include the changed file path.

## Avoid

- Rewriting entire skill files.
- Updating unrelated agents or templates.
- Moving brand facts into global memory.
- Adding examples when a rule is enough.
