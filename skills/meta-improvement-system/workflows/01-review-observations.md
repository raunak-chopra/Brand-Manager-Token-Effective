# Review Observations

Use this workflow to turn workspace observations into concrete improvement candidates.

## Steps

1. Read `logs/2nd-brain/observations.md`.
2. Read `logs/2nd-brain/improvement-candidates.md`.
3. Group repeated patterns.
4. Ignore one-off preferences unless they caused a clear failure.
5. For each durable pattern, add or update one candidate.

## Candidate Checks

- Does this reduce future context load?
- Does this improve routing accuracy?
- Does this prevent repeated corrections?
- Can it be handled by a small file update?
- Is it global, or should it remain brand-specific?
