# Monthly Retrospective

Use this workflow once per month or when the user asks how the bot is improving.

## Inputs

- `logs/context-usage/token-ledger.md`
- `logs/context-usage/dashboard.md`
- `logs/2nd-brain/observations.md`
- `logs/2nd-brain/improvement-candidates.md`

## Output

Save to:

```text
logs/2nd-brain/YYYY-MM-retrospective.md
```

## Sections

- High-token workflows
- Repeated missing inputs
- Router or skill misses
- Templates reused most
- Candidates to action next
- Candidates to decline

Keep the retrospective source-linked and short.
