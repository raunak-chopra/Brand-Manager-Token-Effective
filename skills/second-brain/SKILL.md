# Second Brain

Use when the task asks what to remember, what worked, what failed, what should become reusable, or how to update brand/workspace learnings.

## Inputs

Brand, source output or performance evidence, user confirmation, observed pattern, proposed update target.

## Modes

| Mode | Use When | Destination |
|---|---|---|
| Brand Learning | confirmed brand-specific pattern | `brands/[Brand]/learnings-registry.md` |
| Experiment | active, queued, completed, or invalid test | `brands/[Brand]/experiments-backlog.md` |
| Workspace Improvement | reusable method or rule | relevant `skills/`, `agents/`, `templates/`, or `_core/` file |
| Observation | directional note not yet confirmed | `logs/2nd-brain/observations.md` |

## Workflow

1. Identify source and evidence level.
2. Separate confirmed learning from proposed learning.
3. Keep brand-specific facts out of shared files unless generalized.
4. Update only when requested or when the task is explicitly a learning update.
5. Preserve source pointer and date.

## Output

Confirmed learnings, proposed learnings, destination files, update summary, unresolved questions.
