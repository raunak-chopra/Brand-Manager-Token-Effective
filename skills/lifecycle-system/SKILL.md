# Lifecycle System

Use for email, CRM, nurture, onboarding, newsletters, retention, segmentation, automation, and winback workflows.

## Inputs

Audience segment, lifecycle stage, trigger, offer, proof, list/consent status, platform, timing, CTA, success metric.

## Modes

| Mode | Use When | Optional Reference |
|---|---|---|
| Sequence | multi-email flow | `templates/email/email-sequence.md` |
| Newsletter | recurring broadcast | `_legacy/2026-06-01-pre-superbot/skills/email-lifecycle/references/email-marketing-playbook.md` |
| Automation | trigger and branch logic | `_legacy/2026-06-01-pre-superbot/skills/email-lifecycle/references/automation.md` |
| Segmentation | audience splits and personalization | `_legacy/2026-06-01-pre-superbot/skills/email-lifecycle/references/segmentation.md` |
| Deliverability | sender health or inboxing risk | `_legacy/2026-06-01-pre-superbot/skills/email-lifecycle/references/deliverability.md` |

## Workflow

1. Map lifecycle stage and trigger.
2. Define message job, proof, CTA, and timing.
3. Draft structure before copy.
4. Add segmentation and measurement.
5. Flag consent, platform, and deliverability gaps.

## Output

Flow map, email jobs, copy outline or draft, automation notes, metrics, readiness note.
