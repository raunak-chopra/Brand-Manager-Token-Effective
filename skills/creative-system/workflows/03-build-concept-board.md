# Workflow: Build Concept Board

1. Select 1-3 routes to package.
2. Use `templates/creative/concept-board.md` as the structure.
3. Add the strategic insight, audience tension, campaign platform, key message, visual direction, copy samples, image prompts, and channel notes.
4. Add generated concept slots or image prompt slots when visual production is expected.
5. Include a decision scorecard using `templates/creative/big-idea-scorecard.md`.
6. List missing proof, claim risks, asset/reference gaps, and next production steps.
7. Save shareable concept boards under `outputs/[Brand]/creative/concepts/` when creating files for a named brand.
