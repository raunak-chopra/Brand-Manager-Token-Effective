# Workflow: Produce Image Concepts

1. Confirm brand, platform, placement, ratio, subject, creative angle, mandatory assets, rejected styles, text overlay, and claim limits.
2. Choose generation mode: text-to-image, reference variation, or image edit.
3. Write 2-3 prompt variants per concept using `references/agency-image-generation.md`.
4. Generate or prepare concept visuals when image tools are available and requested.
5. Save generated concepts under `outputs/[Brand]/creative/concepts/` when creating files for a named brand.
6. Update `brands/[Brand]/prompt-library.md`, `brands/[Brand]/asset-inventory.md`, and `brands/[Brand]/generated-image-log.md` when files are created or approved.
7. Run QA for ratio, safe area, unsupported claims, distorted product details, unreadable text, unapproved logos, and rejected styles.
8. Present concept status as exploration, concept-ready, or production-ready pending supplied proof/assets.
