# Workflow: Critique And Improve

1. Identify artifact type: copy, ad, image, campaign, landing page, brand system, or concept.
2. State the intended audience, channel, and action if known.
3. Score the artifact using `references/creative-quality-rubric.md`.
4. Lead with the highest-risk issues: unclear idea, weak audience tension, generic visuals, unsupported claims, poor channel fit, or asset rights gaps.
5. Produce improved versions or revised routes.
6. Explain what changed and why.
7. Close with missing inputs, claim/source/legal risks, asset gaps, and recommended next step.
