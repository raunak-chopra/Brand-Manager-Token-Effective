# Workflow: Develop Creative Territories

1. Load `brands/[Brand]/context-index.md` if a brand is named.
2. Pull audience, category, promise, desired perception, first-use touchpoints, rejected styles, mandatory assets, and claim limits.
3. Use `[To be supplied]` for missing facts instead of inventing them.
4. Identify the audience tension and the category sameness the brand can break.
5. Generate 3-5 creative territories.
6. For each territory, include name, platform, tension, brand role, emotional promise, sensory world, copy language, first executions, channels, proof needs, and avoidances.
7. Score each territory using `references/creative-quality-rubric.md`.
8. Recommend one direction and list references, assets, or proof needed next.
