# Workflow: Generate Big Ideas

1. Define the audience tension, desired perception, brand role, offer, and channel context.
2. Generate 10 rough idea seeds using `references/big-idea-frameworks.md`.
3. Cluster seeds into 3-5 campaign platforms.
4. Expand each platform with:
   - idea name
   - one-line campaign platform
   - why people care
   - ownable device
   - visual world
   - copy samples
   - first 5 assets
   - proof needed
   - risks
5. Score each platform.
6. Recommend one route or next test.
