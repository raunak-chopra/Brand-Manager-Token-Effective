# Creative Territories

A creative territory is an ownable world a brand can repeatedly return to across campaign, copy, design, social, and production. It is not a single headline or moodboard; it is a strategic route with a recognizable feeling.

## Territory Structure

For each territory, define:

- Territory name.
- One-line platform.
- Enemy, tension, or category sameness it fights.
- Audience truth.
- Brand role.
- Emotional promise.
- Sensory world: color, texture, setting, light, pace, sound, and composition.
- Visual language.
- Voice language.
- First executions.
- Channels.
- Proof needs.
- Avoidances.

## Territory Types

Use these as starting lenses, not rigid templates:

- Cinematic premium: high-control craft, restraint, drama, precision.
- Challenger / contrarian: category enemy, sharp contrast, myth-breaking.
- Ritual / lifestyle: repeatable moments, habit, belonging, daily transformation.
- Expert / authority: clarity, confidence, proof, diagnosis, calm command.
- Community / movement: shared identity, language, participation, public signal.
- Surreal metaphor: abstract idea made concrete through memorable imagery.
- Product-as-hero: product mechanism or distinctive feature dramatized visually.
- Founder-led: origin, conviction, obsession, standards, hard-earned belief.
- Cultural moment: timely tension, memeable format, platform-native behavior.
- Transformation arc: before/after world without unsupported performance claims.

## Output Rules

- Generate 3-5 territories.
- Keep each route meaningfully different.
- Make the sensory world specific enough for an image prompt or moodboard.
- Score each route before recommending.
- Use `[To be supplied]` for missing proof, assets, rights, or audience facts.
