# Ad Image Generation Specs

Static ad image guidance lives here. Copy lives in `skills/copy-system/references/ad-creative-copy.md`. Platform placement specs live in `skills/performance-system/references/ad-platform-specs.md`.

## Use For

- Static ad concept images.
- Product mockups.
- Feed/story/display stills.
- Creative brief visuals.
- Image editing instructions.

## Required Before Prompting

- Approved or rejected references.
- Product/subject description.
- Platform and ratio.
- Mandatory brand assets.
- Text overlay, if any.
- Claim/source/legal limits.
- Usage rights for supplied assets.

## Prompt Checklist

- Audience and message job.
- Scene and subject.
- Composition and focal point.
- Style and lighting.
- Brand cues.
- Format and safe area.
- Exact overlay text or "no text".
- Avoidances.

## QA

Reject outputs that include unsupported claims, distorted product details, unreadable text, wrong ratio, unapproved logos, or visual styles the brand rejected.
