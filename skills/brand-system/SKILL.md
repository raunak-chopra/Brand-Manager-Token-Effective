# Brand System

Use for brand foundation, positioning, messaging, voice, architecture, and guideline strategy.

## Inputs

Category, product, audience, promise, proof, desired perception, competitors/references, required rules, rejected styles.

## Modes

| Mode | Use When | Reference Guide | Action Workflow Playbook |
|---|---|---|---|
| **Foundation** | defining vision, purpose, values, founder brief | `references/golden-circle-purpose.md`<br>`references/brand-values-development.md` | `workflows/01-discover-founder.md`<br>`workflows/05-define-purpose.md`<br>`workflows/06-define-values.md` |
| **Positioning** | defining category, zag, differentiator, target | `references/brand-positioning-theory.md` | `workflows/02-research-audience.md`<br>`workflows/03-audit-competitors.md`<br>`workflows/07-define-positioning.md` |
| **Archetypes** | selecting Jungian archetype & combinations | `references/brand-archetype-selection.md` | `workflows/08-select-archetype.md` |
| **Naming** | brainstorming or evaluating brand names | `references/brand-naming-strategies.md` | `workflows/04-name-brand.md` |
| **Voice** | defining brand voice, tone, word constraints | `references/brand-voice-development.md` | `workflows/09-define-voice.md` |
| **Visuals** | establishing visual identity, colors, typography | `references/visual-identity-direction.md`<br>`references/brand-color-psychology.md`<br>`references/brand-typography-systems.md` | `workflows/10-set-visual-direction.md`<br>`workflows/11-choose-colors.md`<br>`workflows/12-select-typography.md` |
| **Guidelines** | compiling final brand rules or brand book | `templates/brand/brand-book.md` | `workflows/13-compile-guidelines.md` |

## Workflow

1. Load brand `context-index.md` first when available.
2. Identify which **Mode** fits the user request.
3. Load the corresponding **Reference Guide** and **Action Workflow Playbook** for that mode.
4. Execute the step-by-step instructions in the workflow playbook, validating findings at each milestone.
5. Close with confirmed facts, recommendations, and missing inputs.

## Output

Strategic recommendations (purpose, positioning, colors, voice), visual style specs, completed worksheets, and next-step guides.
