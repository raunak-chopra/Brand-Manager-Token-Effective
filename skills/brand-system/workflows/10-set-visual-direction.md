# Set Visual Direction

Use to translate strategy into art direction, mood, composition, image style, and identity cues.

## Inputs

Positioning, archetype, voice, audience, approved/rejected references, mandatory assets, usage context, and license constraints.

## Process

1. Load brand context and supplied visual references.
2. Use `references/visual-identity-direction.md` when deeper creative direction is needed.
3. Define visual principles, image style, layout feel, icon/illustration approach, motion/texture notes, and avoided styles.
4. Mark missing assets, licenses, or references as `[To be supplied]`.
5. Save direction in `brands/[Brand]/brand-book.md` or shareable creative briefs in `outputs/[Brand]/`.

## Output

Visual territory, rationale, reference notes, rejected directions, and production-ready creative constraints.
