# Discover Founder

Use to create or refresh the founder brief for a brand.

## Inputs

Brand/product name, category, founder motivation, audience, problem, core promise, proof, rejected styles, first-use touchpoints, and mandatory constraints.

## Process

1. Load `brands/[Brand]/context-index.md` when it exists.
2. Ask only for missing facts that materially affect the founder brief.
3. Separate confirmed facts, founder preferences, assumptions, and `[To be supplied]` gaps.
4. Capture the brand origin, customer problem, point of view, desired perception, operating constraints, and first execution priorities.
5. Save brand memory in `brands/[Brand]/brand-intake.md` or `brands/[Brand]/context-index.md`; save shareable briefs in `outputs/[Brand]/`.

## Output

A concise founder brief with source notes, open questions, and next recommended brand-system workflow.
