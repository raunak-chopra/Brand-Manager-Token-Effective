# Define Values

Use to define brand values that affect decisions, copy, culture, and customer experience.

## Inputs

Founder brief, operating principles, customer promise, tradeoffs, anti-values, and proof of actual behavior.

## Process

1. Load brand context and purpose notes.
2. Use `references/brand-values-development.md` when values need structure.
3. Identify candidate values, anti-values, behavioral proof, and decision rules.
4. Reject generic values that a competitor could claim unchanged.
5. Save values in `brands/[Brand]/brand-book.md` and update `context-index.md` with the short version.

## Output

Three to six values with behaviors, anti-values, decision tests, and unresolved proof gaps.
