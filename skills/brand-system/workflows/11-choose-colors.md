# Choose Colors

Use to select or evaluate a brand color palette.

## Inputs

Brand strategy, desired perception, category norms, accessibility needs, required colors, rejected colors, and usage contexts.

## Process

1. Load brand context and visual direction.
2. Use `references/brand-color-psychology.md` when rationale or examples are needed.
3. Define primary, secondary, neutral, accent, semantic, and accessibility use cases.
4. Check contrast for core text/background pairings when color values are supplied.
5. Save palette rules in `brands/[Brand]/brand-book.md` and reusable tokens in `outputs/[Brand]/` if requested.

## Output

Palette with hex values where supplied, usage rules, contrast notes, and `[To be supplied]` gaps.
