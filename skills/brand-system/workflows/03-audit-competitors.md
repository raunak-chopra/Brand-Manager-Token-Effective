# Audit Competitors

Use to compare competitors, substitutes, category norms, messaging patterns, and white-space opportunities.

## Inputs

Brand context, competitor list, URLs/files supplied by the user, category, target audience, and desired positioning.

## Process

1. Load brand context and only the supplied competitor sources.
2. If competitor facts need current verification, browse or ask for source links before making claims.
3. Compare positioning, proof, pricing/offer framing, visual patterns, voice, and acquisition channels.
4. Separate observed evidence from strategic interpretation.
5. Save reusable competitor notes under `brands/[Brand]/reference-library/`.

## Output

Competitor pattern map, differentiation opportunities, risks, missing evidence, and recommended positioning implications.
