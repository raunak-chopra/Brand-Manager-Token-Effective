# Research Audience

Use to define target audience, jobs-to-be-done, pains, buying triggers, objections, and language patterns.

## Inputs

Brand context, product/category, audience hypothesis, competitors/references, available research sources, and performance or customer evidence.

## Process

1. Load `brands/[Brand]/context-index.md` and any supplied customer/research files.
2. Gather missing audience facts directly from the user only when local context cannot answer them.
3. Use `skills/insight-system/references/jtbd-psychographic-research.md` when deeper motivation analysis is needed.
4. Mark unsourced audience claims as assumptions or `[To be supplied]`.
5. Save durable audience memory in `brands/[Brand]/brand-intake.md`, `brands/[Brand]/context-index.md`, or `brands/[Brand]/reference-library/`.

## Output

Audience segments, jobs, pains, triggers, objections, customer language, evidence quality, and research gaps.
