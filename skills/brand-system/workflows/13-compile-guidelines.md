# Compile Guidelines

Use to compile a complete brand book or guidelines document from existing brand memory.

## Inputs

Brand intake, context index, brand book sections, visual rules, voice rules, claim constraints, and approved assets.

## Process

1. Load `brands/[Brand]/context-index.md` first, then only the needed brand files.
2. Identify missing sections and mark them `[To be supplied]` instead of inventing.
3. Compile strategy, audience, positioning, voice, visual identity, copy rules, assets, claims, and governance.
4. Save durable brand memory in `brands/[Brand]/brand-book.md`.
5. Save shareable/client-ready versions in `outputs/[Brand]/`.

## Output

Compiled guidelines with draft/approved status, source notes, missing inputs, and next maintenance steps.
