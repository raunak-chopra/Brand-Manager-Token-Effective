# Select Typography

Use to choose or evaluate typography systems for brand and marketing outputs.

## Inputs

Brand personality, content density, digital/print context, font license status, mandatory fonts, and accessibility constraints.

## Process

1. Load brand context, voice, and visual direction.
2. Use `references/brand-typography-systems.md` when selection logic is needed.
3. Define display, body, utility, fallback, scale, and usage rules.
4. Treat font licensing as `[To be supplied]` unless a license source is supplied.
5. Save typography rules in `brands/[Brand]/brand-book.md`.

## Output

Typography recommendation with roles, fallbacks, scale notes, licensing status, and open checks.
