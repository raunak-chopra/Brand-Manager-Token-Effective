# Copy System

Use for marketing copy, rewrites, hooks, headlines, CTAs, page sections, ads, social snippets, and claim-safe copy review.

## Inputs

Audience, channel, awareness stage, offer, product facts, proof, claim limits, voice, desired action, format.

## Modes

| Mode | Use When | Reference Guide | Action Workflow Playbook |
|---|---|---|---|
| **Messaging** | creating value proposition, target messaging matrix | `references/brand-messaging-architecture.md` | `workflows/01-create-messaging-framework.md` |
| **Pitch** | writing founder stories or elevator pitches | `references/elevator-pitch-techniques.md` | `workflows/03-write-elevator-pitch.md` |
| **Tagline** | generating brand taglines and truelines | `references/tagline-creation-strategies.md` | `workflows/02-create-tagline.md` |
| **Copywriting** | writing landing page copy, hooks, CTAs, ads | `references/hooks-builder.md`<br>`references/conversion-psychology.md` | `workflows/04-write-marketing-copy.md` |
| **Scripting** | writing sponsor or video/audio marketing scripts | `references/scriptwriting-methodology.md` | `workflows/05-write-sponsor-script.md` |
| **Human-Check** | auditing copy to ensure it sounds natural and human | `references/ai-writing-detection.md` | Proactively run on drafts |

## Workflow

1. Load brand `context-index.md` first when available.
2. Identify the active copywriting **Mode**.
3. Load the corresponding **Reference Guide** and **Action Workflow Playbook**.
4. Draft the primary versions following the playbook instructions.
5. Apply the **Human-Check** protocol (`references/ai-writing-detection.md`) to remove typical AI terminology and robotic structures.
6. Present the output with variants and CTA analysis.

## Output

Primary copy, headlines/CTA variants, script tables, formatting guides, and copywriter rationales.
