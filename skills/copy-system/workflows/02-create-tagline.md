# Create Tagline

Use to generate, evaluate, or refine taglines and short brand lines.

## Inputs

Positioning, audience, promise, proof, voice, rejected words, desired length, and usage context.

## Process

1. Load brand context and messaging framework when available.
2. Ask for any hard constraints before ideation.
3. Generate routes: direct benefit, belief, contrast, category claim, emotional outcome, and memorable phrase.
4. Evaluate each option for clarity, ownability, truthfulness, voice fit, and claim risk.
5. Save shortlisted options and final selection in `brands/[Brand]/brand-book.md` or `outputs/[Brand]/`.

## Output

Tagline options, rationale, risk notes, and selected recommendation if enough context is supplied.
