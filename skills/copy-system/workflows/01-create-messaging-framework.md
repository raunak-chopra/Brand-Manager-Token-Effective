# Create Messaging Framework

Use to create the core messaging architecture for a brand, offer, or campaign.

## Inputs

Brand context, audience, positioning, promise, proof, objections, voice, offer, claim limits, and destination/channel.

## Process

1. Load `brands/[Brand]/context-index.md` when available.
2. Ask directly for missing audience, offer, proof, or conversion-event details that affect the framework.
3. Define value proposition, pillars, audience pains, proof points, objections, message hierarchy, and CTA logic.
4. Mark unsupported claims, performance metrics, and legal limits as `[To be supplied]`.
5. Save durable messaging rules in `brands/[Brand]/brand-book.md` or `brands/[Brand]/prompt-library.md`; save shareable output in `outputs/[Brand]/`.

## Output

Messaging framework with draft status, source notes, claim gaps, and recommended next copy workflow.
