# Write Sponsor Script

Use for sponsored creator reads, integrations, short-form scripts, and affiliate-style copy.

## Inputs

Creator/channel context, sponsor/product, audience, offer, proof, mandatory talking points, banned claims, CTA, and timing.

## Process

1. Load brand context and any supplied creator voice samples.
2. Clarify product truth, offer terms, compliance limits, and required disclosures before drafting.
3. Build hook, problem/setup, sponsor bridge, proof, offer, CTA, and optional variants.
4. Keep claims and endorsements in draft status until proof and approval are supplied.
5. Save scripts in `outputs/[Brand]/` and durable copy rules in `brands/[Brand]/prompt-library.md` when useful.

## Output

Sponsor script with timing notes, alternate hooks, CTA variants, disclosure reminders, and approval gaps.
