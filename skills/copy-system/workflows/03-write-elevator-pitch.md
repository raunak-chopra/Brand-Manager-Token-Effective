# Write Elevator Pitch

Use to write concise pitch versions for introductions, sales calls, investor notes, and social bios.

## Inputs

Audience, problem, promise, differentiator, proof, tone, context, and desired next action.

## Process

1. Load brand context and messaging framework when available.
2. Clarify target listener and pitch context if missing.
3. Draft one-line, 15-second, 30-second, and 60-second versions when useful.
4. Keep proof and performance claims as draft unless source-backed.
5. Save reusable pitch language in `brands/[Brand]/brand-book.md` or shareable output in `outputs/[Brand]/`.

## Output

Pitch variants with usage notes, CTA options, source/proof gaps, and practice refinements.
