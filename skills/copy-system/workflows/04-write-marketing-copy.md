# Write Marketing Copy

Use for landing pages, ads, emails, social posts, headlines, scripts, and conversion copy.

## Inputs

Copy type, audience, offer, goal/CTA, channel, voice, proof, objections, constraints, and compliance limits.

## Process

1. Load brand context and the smallest relevant copy references.
2. Ask directly for missing copy-critical details: audience, offer, CTA, proof, tone, and required inclusions/exclusions.
3. Draft copy using direct language, varied sentence rhythm, concrete details, and the brand voice.
4. Run a human-sounding and claim-safety pass using `references/ai-writing-detection.md` and `_core/SHARED-PROTOCOLS.md`.
5. Save reusable brand copy in `brands/[Brand]/prompt-library.md` or shareable deliverables in `outputs/[Brand]/`.

## Output

Draft copy clearly marked as draft when claims, offer terms, legal rules, or source proof are missing.
