# Ad Creative Copy

Use for hooks, angles, headlines, primary text, descriptions, CTAs, and copy variants.

## Inputs

Audience, problem, promise, proof, offer, platform, funnel stage, brand voice, claim limits.

## Angle Types

| Angle | Use When | Avoid |
|---|---|---|
| Pain relief | audience has urgent friction | exaggerating severity |
| Outcome | result is concrete and proven | unsupported performance claims |
| Proof | testimonials/data are available | vague "trusted by" claims |
| Mechanism | product method is differentiated | jargon without benefit |
| Comparison | alternative is familiar | unverified competitor claims |
| Offer | promo or package drives action | unclear terms |

## Copy Blocks

- Hook: one clear reason to stop.
- Primary text: problem, promise, proof, action.
- Headline: specific benefit or offer.
- Description: supporting detail only if placement uses it.
- CTA: one action.

## Variant Rule

Create variants by changing one variable at a time: angle, proof, audience segment, offer framing, or CTA.
