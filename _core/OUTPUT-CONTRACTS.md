# Output Contracts

Centralized safety, compliance, and readiness checks. Use this instead of repeating rules in every agent or skill.

## Claim Safety

Do not publish or treat as final:

- unsourced performance claims
- invented statistics
- unverified competitor comparisons
- unconfirmed testimonials
- guarantees, discounts, or offer terms not supplied by the user
- legal, medical, financial, or regulated claims without explicit support
- font/license assertions without source proof

Use `[To be supplied]` where proof is missing.

## External Copy Check

Before final copy, check:

- brand voice fit
- audience fit
- channel fit
- claim proof
- legal/compliance limits
- offer terms
- source availability
- single primary CTA unless format requires otherwise

## Quality Gates

For substantial deliverables, check:

| Gate | Pass Condition |
|---|---|
| Source integrity | Claims, metrics, competitor facts, and legal/compliance notes have sources or `[To be supplied]`. |
| Brand consistency | Output matches the active brand context, voice, positioning, and rejected styles. |
| Channel fit | Format, CTA, length, and asset requirements fit the intended channel. |
| Creative quality | Idea is distinct, audience-relevant, visually ownable, channel-ready, and not dependent on unsupported claims. |
| Asset/license readiness | Fonts, images, templates, and generated assets have usage status or `[To be supplied]`. |
| Performance readiness | Tracking, primary conversion event, and metric caveats are stated when performance is discussed. |
| Missing inputs | Blocking and non-blocking gaps are separated clearly. |

## Image Generation Readiness

Before treating generated or edited images as review-ready, check:

- generation mode is stated
- approved references/assets are listed
- ratio, placement, and safe area are stated
- concept vs final status is stated
- unsupported text, claims, logos, likenesses, and badges are excluded
- asset/license gaps are listed

## Readiness Note

For substantial deliverables, close with:

```text
Readiness: Draft / Review-ready / Publish-ready pending supplied proof
Creative status: Exploration / Concept-ready / Production-ready pending supplied proof/assets
Inputs used:
Missing facts:
Claim/source/legal risks:
Asset/reference gaps:
Suggested next step:
```

## Recommendation Standard

Every recommendation should state:

- perception created
- why it fits the brand
- where to use it
- what to avoid

## Formatting

Lead with the answer. Keep sections compact. Prefer tables only when they make comparison easier.
