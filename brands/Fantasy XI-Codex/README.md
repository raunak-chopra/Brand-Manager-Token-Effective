# Fantasy XI-Codex Asset Pack

Fresh original asset pack for the fantasy football channel.

Working brand direction:
- Channel: Deadline XI
- Host/persona: Papa Ranjeet
- Voice: Hinglish
- Formats: faceless tactical-board videos and face-on-camera variants

Important:
- These are original source assets created for this workspace.
- Envato is used as visual reference direction only: sports broadcast packages, soccer lower thirds, scoreboards, player cards, and opener templates.
- No downloaded Envato file is included unless separately supplied by the user.

## Folders

- `logos/` - source logo systems
- `banners/` - YouTube and channel banner source layouts
- `video/` - backdrop, intro storyboard, lower thirds, and video overlays
- `social/` - Instagram story, carousel, and highlight cover sources
- `thumbnails/` - YouTube thumbnail source layouts
- `fonts/` - font pairing notes and Envato/font sourcing checklist
- `envato-reference/` - asset search terms and replacement guidance
- `templates/` - reusable content templates
