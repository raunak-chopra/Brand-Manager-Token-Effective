# Brand Folders

Brand-specific source of truth lives here.

```text
brands/
  _template/
  [Brand Name]/
    context-index.md
    brand-intake.md
    memory.md
    reference-index.md
    learnings-registry.md
    experiments-backlog.md
    brand-guidelines/
    reference-library/
    assets/
```

## Rule

Read `context-index.md` first. Load deeper files only when the task needs them.

Final/shareable outputs belong in `outputs/[Brand Name]/`, not inside the brand source folder.
