# Asset Checklist

## Strategy

- [ ] Brand intake is complete enough to make decisions
- [ ] Audience is specific
- [ ] Core promise is clear
- [ ] Competitors are identified
- [ ] Rejected styles are documented

## References

- [ ] Approved references are tagged
- [ ] Rejected references are tagged
- [ ] Competitor references are separated
- [ ] Font references include license status
- [ ] Color references include HEX/RGB/CMYK/Pantone where relevant

## Moodboards

- [ ] 2-3 territories created
- [ ] Each territory has a strategy
- [ ] Each territory has risks
- [ ] Territories are scored
- [ ] One direction is recommended

## Brand Book

- [ ] Logo rules included
- [ ] Color hierarchy included
- [ ] Typography hierarchy included
- [ ] Imagery rules included
- [ ] Layout rules included
- [ ] Application guidance included
- [ ] Do/don't rules included
- [ ] Governance included

## Production

- [ ] Source files are in `assets/`
- [ ] Exports are clearly named
- [ ] Font licenses are confirmed
- [ ] Legal / claims rules are confirmed
- [ ] Print/vendor constraints are confirmed
